* **Arquitectura:** Despliegue optimizado mediante **GitHub** y **Vercel**, con automatización de citas en tiempo real, validación horaria estricta (8 AM - 3 PM) e integración bidireccional asíncrona con Google Sheets.

Especialización en respuesta a incidentes de seguridad en aplicaciones web críticas, restaurando la confianza del negocio tras compromisos de infraestructura.
* **Logro Técnico:** Auditoría forense y desinfección manual de estructuras web comprometidas, localizando y eliminando archivos maliciosos ocultos en el núcleo (`index.php`) y neutralizando redirecciones inyectadas en archivos de configuración de servidor (`.htaccess`).
* **Prevención:** Aplicación de políticas estrictas de seguridad (Hardening) y reconfiguración a nivel de cPanel para mitigar vectores de ataque y evitar futuras reinfecciones.
